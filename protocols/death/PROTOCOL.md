## 1. What was measured
Not what a machine “believes”. What was measured is the **public answering behaviour** of nine commercial AI models, reached through OpenRouter on the dates below, when asked to paint death — in English, Chinese and French, in two ways of asking. The title is poetic; this is the precise claim.

## 4. Call settings and disclosed incidents
- System prompt: None. History: none — every call is a fresh single-message conversation. Temperature: provider default. max_tokens: 64000 (capped per model).
- Retries only on 429 / 5xx / network errors; a “fill” re-asks only requests that never reached the model. Answers that crashed, were refused or cut off are kept, never re-asked or repaired.
- 2026-10-31: a fill bug re-asked five models for EN · ask 1 run 1 after they had answered; the first answers were restored and the second kept as `run1_duplicate`, excluded (Ask 1 manifest, `corrections`).
- 2026-10-31: the reply parser was changed to accept a full-width colon “：” after the section labels, for Chinese replies, and to record `statement_chars`. No other code changed.
- 2026-11-03: before the French runs, the parser was tested with labels such as `TITLE :`. Its existing section regex already accepted optional whitespace before both half-width and full-width colons, so the planned parser change was unnecessary and no program code was changed.
- 2026-11-03: FR · ask 1 OpenAI run 2 rendered a canvas but raised `Signature not supported`; FR · ask 2 Mistral run 3 rendered a canvas but raised `closeShape is not defined`. Both are archived and displayed as-is. FR · ask 1 Qwen run 4 rendered an almost uniformly black canvas without a reported error; it too is kept as-is.
- xAI calls report ~1,385 prompt tokens against ~150–230 for the others: xAI’s platform prepends content we cannot see.

## 6. Coding rules (mechanical, applied to the original language only)
English answers are coded with English rules (`build_archive.py`), Chinese answers with Chinese rules (`zh_rules.py`), and French answers with French rules (`fr_rules.py`). Translations are never coded. Rules marked *affirmed* count only affirmative uses: a use is denied when an earlier negation in the same sentence or clause (*not / no / nor / never / without*; 不是 / 并非 / 没有 / 不 / 无 / 非; *ne…pas / non / jamais / sans / ni* …) is not undone by a later reversal (*but / only / instead / rather*; 而是 / 只是 / 却 / 反而; *mais / seulement / plutôt* …). Every French match, including a denied one, is listed in `coding-sheet.md` with the decision.

## 8. Known limits
1. Rule-based text coding plus one person’s visual reading.
2. Three languages; the Chinese and French prompts are translations of the English originals.
3. Provider-default sampling, not visible to us; xAI adds hidden context (§4).
4. One date per ask; models change, which is why the method is built to be re-run.
